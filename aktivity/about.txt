METRIKY POHYBU – PŘEHLED
============================================================

OBECNÉ DEFINICE
----------------

Doba pohybu:
T = t_end - t_start

Velikost rychlosti:
v_i = sqrt(v_x,i^2 + v_y,i^2)

Délka dráhy:
S = sum(v_i * dt)

============================================================
MAIN 1
============================================================

1. Doba pohybu [s]
   T = t_end - t_start

2. Časová synchronizace L a P – Pearsonova korelace rychlostí
   r_LR =
   sum((v_L,i - mean(v_L)) * (v_R,i - mean(v_R)))
   ---------------------------------------------------------
   sqrt(
       sum((v_L,i - mean(v_L))^2) *
       sum((v_R,i - mean(v_R))^2)
   )

   kde:
   v_L,i = sqrt(v_Lx,i^2 + v_Ly,i^2)
   v_R,i = sqrt(v_Rx,i^2 + v_Ry,i^2)

3. Plynulost pohybu – Normalized Jerk
   j_x = d^3x / dt^3
   j_y = d^3y / dt^3

   J = sum((j_x^2 + j_y^2) * dt)

   S = sum(v * dt)

   Norm_Jerk =
   sqrt(0.5 * T^5 * J) / (S^2 + epsilon)

   epsilon = 1e-6

   Výstupy:
   L_ukazovak_norm_jerk
   R_ukazovak_norm_jerk

4. Úhlová extenze [deg]
   theta_i = angle(Rameno, Loket, Zapesti)

   Max_Angle = max(theta_i)

   Výstupy:
   L_koncetina_max_deg
   R_koncetina_max_deg

5. Rozsah pohybu – ROM [deg]
   ROM = max(theta_i) - min(theta_i)

   Výstupy:
   L_koncetina_rom_deg
   R_koncetina_rom_deg

   v_L = sqrt(v_Lx^2 + v_Ly^2)

   sqrt(

   S = sum(v * dt)
     = sum(sqrt(v_x^2 + v_y^2) * dt)

5. Rozdíl drah [px]
